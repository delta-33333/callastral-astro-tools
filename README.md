## Qu'est-ce que l'ascendant ?
L'ascendant est le signe du zodiaque qui se levait à l'horizon est au moment précis de votre naissance. Il change environ toutes les deux heures : pour le calculer, il faut la **date**, l'**heure exacte** et le **lieu** de naissance. Il décrit traditionnellement votre « façade » : première impression, allure, manière d'aborder le monde. Sans heure de naissance, l'ascendant ne peut pas être calculé de façon fiable (l'heure figure sur la copie intégrale de l'acte de naissance).
